# attendance-prediction-system
A web-based Attendance Prediction System that calculates current attendance, determines attendance status, and predicts the number of classes a student needs to attend to meet the required attendance percentage.

## Project Overview

The Attendance Prediction System helps students monitor their attendance and plan their future classes.

The system takes the following inputs:

- Total classes held
- Classes attended
- Required attendance percentage
- Classes still remaining

It then calculates the current attendance percentage and provides a recommendation for the remaining classes.

## Features

- Calculate current attendance percentage
- Display attendance status as **SAFE** or **SHORTAGE**
- Calculate how many classes can be missed when attendance is sufficient
- Calculate how many remaining classes need to be attended
- Predict whether the required attendance percentage can be achieved
- Provide a clear attendance recommendation

## Project Output

The system displays:

- **Current Attendance**
- **Attendance Percentage**
- **Attendance Status**
- **Classes that can be missed**
- **Classes that need to be attended**
- **Final Attendance Recommendation**
